# Explicit product fault policy development

Actual seven-case Google RED→GREEN exercises the C11 policy and strong SDK
observer. The Native application also exits zero with real owner/producer
threads. Source/command/XML identities and an independent read-only review are
preserved. This is current-source development, not a committed SDK qualification.

The product owns its record and stable explicit output port. The example port
returns UNSUPPORTED and does not invent GPIO/safe levels, reset or loan cleanup.
Cortex-M4 -fshort-enums probe: record24B/snapshot12B; other ABIs may differ.
Final SDK pin, full CTest/MCU images and physical acceptance are separate.
