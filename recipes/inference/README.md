# 固定量化图的软件参考

本片段展示一个明确的三输入、四隐藏节点、二输出 C11 数值图，通过
`Nexus::AlgorithmsCMSISNN` 实际执行锁定 CMSIS-NN 的 signed-int8 dense 内核。
权重在源码中手工给定，用于检查量化、ReLU、串联和输出消费；它没有训练结果或
真实产品分类准确率声明。模型、训练数据、物理特征和阈值仍属于外部产品。

应用显式调用 `nexus_add_cmsis_nn()` 并链接 `Nexus::AlgorithmsCMSISNN`，编译
`inference_reference.c`，包含本地公共头。三个输入是预先量化的数值，不直接表示
电流、温度或振动单位。两个输出为 logits，较大者的索引为结果，相等时选择零；
logits 及差值都不是概率。图中 multiplier 为 `INT32_MAX`、shift 为零，隐藏层
限制到 0..127，输出限制到 -128..127，bias 使用累加器单位。

例如输入 `[10,0,0]` 输出 `[6,-6]`／索引零，`[0,10,10]` 输出 `[-16,16]`／索引一。
实际产品先定义有单位、有效性和版本的特征快照，再转换为模型所需量化范围。
控制 IRQ 可以向普通执行者交接有界快照；应用安排推理预算和结果有效期。

模型数组只读共享，四字节隐藏向量和结果采用本次调用的栈存储。没有模型注册表、
worker、文件装载器、堆或跨调用借用。先检查返回值再读取结果。调用者保证输入与
结果分离，且不在并发写入特征的同时调用。本片段不改变执行器目标或保护策略。

Native GoogleTest 执行生产 C 和真实上游内核。ARM 编译、链接资源和实际设备
时延分别验证；未执行物理测量时保持 `not_executed`。
