# 单轴位置／速度／电流软件参考

本例把平台 `Nexus::AxisControl`、真实 C 电流 PI 与独立带载直流电机模型
连成有限时长闭环。它验证软件接口和控制链路，不能作为实际电机、功率板、
FOC、机械安全、调参稳定性或实时性能的验收依据。

```text
一次有限授权命令 ──► AxisControl（1 ms）
                       位置轨迹 → 位置 P → 速度 PI → 电流限幅
                                                        │ A
量化编码器 ─────────────────────────────────────────────┘
量化电流 ──► 电流 PI（50 us） ──► 暂存电压 V
                ▲                       │ 延迟一个模型周期
                └──── 独立 L/R/Ke + J/Kt/B + 负载模型
                                    │
                              独立真值 → 结果评估
```

`servo_control.c` 只接收已校准的传感器值和公共 Axis 输出，不读取模型状态。
`servo_sil.c` 负责明确的采样时序、实验和统计；模型与双轮例共用
`../differential_drive/sil_model.c`，没有第二份电机算法。

## 运行

使用包含 `Nexus::AxisControl` 的已安装 Source SDK：

```sh
cmake -S recipes/control/servo_axis -B build/servo-axis \
  -DNexus_DIR=/absolute/sdk/lib/cmake/Nexus
cmake --build build/servo-axis --target servo_axis_reference
ctest --test-dir build/servo-axis --output-on-failure
```

固定参考运行 6.001 s：目标位置 1 rad，最大速度 2 rad/s、加速度 4 rad/s²、
电流限幅 ±3 A；1.5 s 加入 +0.03 Nm 阻力，2 s 在控制边界采用完整参数
revision 2。到位由量化位置误差 ≤0.005 rad、速度 ≤0.02 rad/s 连续保持
20 ms 确认；轨迹完成本身不表示到位。

模型参数显式给出：R=1 Ω、L=0.01 H、Ke=0.1 V/(rad/s)、Kt=0.1 Nm/A、
J=0.002 kg·m²、B=0.02 Nm/(rad/s)、12 V 母线。编码器每转 1,000,000
计数，电流每码 0.0005 A。控制器的校准参数独立保存，不能从模型真值反推。
该标量 DC 示例不包含逆变器、换相、死区、机械柔性或噪声。

## 判据与边界

固定窗口 `[4 s, 5 s)` 必须具有完整的 1000 个 1 ms 记录。缺失记录不会
补零。输出包含样本数、参数版本、命令采用／轨迹完成／实测到位时间、位置／
速度／电流峰值及 RMS、测量位置与独立模型真值。软件通过条件为：电流误差
峰值 <0.02 A；速度模式与位置模式的速度误差峰值 <0.03 rad/s；位置模式
还要求位置误差峰值 <0.01 rad 和实测到位。阈值仅用于这里的显式模型。

速度测量描述前一个 1 ms 区间，因此对照该区间的旧速度参考；边界瞬时 ADC
对照采样时仍有效的旧电流目标。边界之后才算出的新目标不会倒填到已经
发生的观测区间。位置采样则对照同一时刻的轨迹位置参考。

`example_servo_experiment_t` 可选择 CURRENT／VELOCITY／POSITION、下降电流
限额、受控停止、授权过期、缺样和传感器失效；GoogleTest 执行实际生产 C
与这些负例。电流不足不能虚构负载转矩；关闭反馈增益后，即使轨迹完成也
不能通过到位。电流模式直接由量化 ADC 闭环，不把命令写进模型状态。

受控停止关闭命令准入并继续零速调节。默认 `HOLD_ZERO_VELOCITY` 保持软件
速度 PI 工作，不能证明位置保持、制动或机械支撑；`INHIBIT_AFTER_DWELL`
在实测零速驻留后退出算法电流，授权过期保留 TIMEOUT。停止后不再采用本次
实验尚未应用的参数变更，不会自动复位或重新授权。命令采用时刻和评估器
观察到的模型停稳时刻分别记录。

传感器故障直接返回错误并保留调用者尚未发布的报告。实际产品必须另外
停止输出并排空 I/O，不能把报告不变、零电压计划或 Axis 状态当作功率级
已经停机的证据。
