# Historical industrial application requirements

`industrial-reference.json` is a byte-for-byte historical application baseline
from [Nexus `069dcf14`](https://github.com/X-Gen-Lab/nexus/blob/069dcf14f9cb1cd6fc4a869d87bf9827b91ce306/docs/requirements/industrial-reference.json).
Its SHA-256 is `5ff3a306adf7d8c9d376622df803340bec060e28b25135cf21f1d987f45499ae`.

The old schema-1 product requirements include control-loop budgets and
manufacturing identity. They belong to application/product planning in this
repository. The preserved status and evidence refer only to that historical
baseline, including its recorded host result. They establish no acceptance of
the current Nexus platform, no new product qualification, and no physical HIL.
Original evidence paths refer to that historical Nexus snapshot; they are not
new evidence files supplied or revalidated by this repository.

Current generic Nexus acceptance requirements are maintained separately in
`docs/requirements/platform.json` in the pinned platform source. This historical
file does not define the platform's present traceability gate or source SDK API.
